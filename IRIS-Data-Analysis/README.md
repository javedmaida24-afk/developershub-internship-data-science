# IRIS-Data-Analysis
Iris data set analysis using Python, Pandas, Seaborn and Matplotliv 

## Objective
The objective of this task is to understand and visualize the Iris dataset using Python libraries.

## Tools Used
- Python
- Pandas
- Seaborn
- Matplotlib
- Google Colab

## Approach
1. Loaded the Iris dataset using seaborn.
2. Explored dataset structure using shape, columns, and head functions.
3. Performed data analysis using summary statistics.
4. Created visualizations including:
   - Scatter plot
   - Histogram
   - Box plot

## Results and Insights
- The dataset contains 150 rows and 5 columns.
- Different species show clear differences in petal and sepal measurements.
- Visualization helped in understanding data distribution and relationships.

## Conclusion
This project demonstrates basic data analysis and visualization skills using Python.
